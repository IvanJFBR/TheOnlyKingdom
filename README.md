# The Only Kingdom

A role-playing game created using RPG Maker MZ.

## Lore Synopsis
A story about a world with 4 kingdoms. Once, there was a fifth kingdom that controlled all the others, but it mysteriously disappeared...

## Technical Details
- Engine: RPG Maker MZ
- Mapping: Tiled
- Plugins: VisuStella MZ, Parallax mapping, etc.
